# Rudenko Nail School — «Укріплення без довжини»

Лендинг онлайн-курсу. Статичний проєкт: HTML + CSS + JS, без збірки й залежностей.

## Структура

```
index.html      — розмітка сторінки
style.css       — стилі
script.js       — скрипти
hero.jpg        — головне фото
gallery-1.jpg   — фото роботи
gallery-2.jpg   — фото роботи
gallery-3.jpg   — фото роботи
gallery-4.jpg   — фото роботи
```

> **Усі фотографії знаходяться в корені проєкту (не в папці `assets`).**

Відео підключене через YouTube Embed.

## Як опублікувати на GitHub Pages

1. Створи новий репозиторій на GitHub.
2. Завантаж всі файли проєкту в корінь репозиторію:
   - index.html
   - style.css
   - script.js
   - hero.jpg
   - gallery-1.jpg
   - gallery-2.jpg
   - gallery-3.jpg
   - gallery-4.jpg
3. Відкрий **Settings → Pages**.
4. У розділі **Build and deployment** вибери:
   - **Source:** Deploy from a branch
   - **Branch:** main
   - **Folder:** /(root)
5. Натисни **Save**.
6. Через 1–2 хвилини сайт буде доступний за адресою:

`https://<твій-акаунт>.github.io/<назва-репозиторію>/`
